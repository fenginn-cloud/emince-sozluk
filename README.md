# Emince Sözlük 🥜

Arkadaşımız **Emin**'in kendince icat ettiği efsane kelimelerin resmi (şaka) sözlüğü.

## Canlı site
GitHub Pages ile yayında. (Settings → Pages → Deploy from a branch → `main` / `root`)

## Özellikler
- 🎰 Rastgele Emince kelime makinesi
- 🔊 Sesli söyleme
- 🔍 Kelime arama
- ✍️ Ziyaretçinin kendi kelimesini eklemesi (tarayıcıda saklanır)
- 🥜 Uçuşan fıstıklar

## Kelime eklemek (kalıcı)
`index.html` içindeki `words` dizisine yeni satır ekle:
```js
{w:"Kelime", t:"tür", m:"Anlamı", ex:"Örnek <b>cümle</b>."},
```
